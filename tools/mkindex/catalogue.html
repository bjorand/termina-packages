pkg

pkg ships with TERMINA. The machine only needs to be online.

CommandWhat it does
pkg updateFetch the package list. Run it now and then to see what's new.
pkg list [-i]Available packages (-i: installed only).
pkg search <word>Search names and descriptions.
pkg info <name>Details of a package.
pkg install <name>...Install, with its dependencies.
pkg upgrade [name...]Upgrade (everything by default).
pkg remove [-f] <name>...Uninstall (-f: even if another package depends on it).
pkg url [address]Show or change the registry in use.

How it works

  • pkg update downloads index.lua, the list of packages with the size and SHA-1 of every file.
  • pkg install downloads the files one by one, checks each SHA-1, then installs the package into A:\pkg\<name>\. If anything fails, the version already installed stays in place.
  • A package's commands run at the A> prompt; its apps show up on the win desktop.
  • To use another registry (a fork, or a local test server): pkg url http://192.168.1.10:8000/.

Contribute

Anyone can publish a package: a folder, a manifest, a pull request.

  1. Fork the repository and copy packages/{{.Example}}/ to packages/<your-name>/.
  2. Write the package.lua manifest, then add your files.
  3. Check with go run ./tools/mkindex, then open a pull request. CI runs the same checks.
  4. Once merged, the package is listed here and reaches every machine after a pkg update.
-- packages/snake2/package.lua
return {
  name = "snake2",          -- = folder name
  version = "1.0.0",        -- X.Y.Z
  description = "Snake in color",
  author = "Ada Lovelace",  -- optional
  license = "MIT",          -- optional
  bin = { "snake2" },       -- optional: A> commands
  depends = { "tui" },      -- optional: other packages
}

Rules

  • Files can be anything (Lua programs, shell scripts, PICO-8 carts, data...). They sit flat in the folder, 64 KB at most each, 256 KB per package, and are installed as-is in A:\pkg\<name>\.
  • Lua files must be valid Lua 5.4 (CI checks the syntax): 32-bit numbers, no io or os, and the TERMINA API (term, key, fs, net, win...).
  • Commands: each name in bin needs its own <name>.lua. Pick names that won't collide.
  • Modules: require "<package>.util" loads A:\pkg\<package>\util.lua.
  • Desktop apps: a file whose header has -- @app Name (and optionally -- @icon name) appears on the win desktop.
  • Versions: any change to a published package must bump its version, or CI rejects the pull request.

Full details in the contributor guide.
