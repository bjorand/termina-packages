Mode d'emploi

La commande pkg est livrée avec TERMINA. Il faut juste que la machine soit connectée au réseau.

01
pkg update

Récupère la liste des logiciels. À refaire de temps en temps pour voir les nouveautés.

02
pkg install nom

Télécharge le logiciel et ses dépendances dans A:\pkg\nom\, en vérifiant chaque fichier (SHA-1).

03
nom

Ses commandes se lancent au prompt, ses applications apparaissent sur le bureau win.

A>pkg
pkg update                  recuperer la liste des packages
pkg list [-i]               packages disponibles (-i : installes)
pkg search <mot>            chercher dans les noms et descriptions
pkg info <nom>              details d'un package
pkg install <nom>...        installer (avec ses dependances)
pkg upgrade [nom...]        mettre a jour (tout par defaut)
pkg remove [-f] <nom>...    desinstaller (-f : meme si un autre en depend)
pkg url [adresse]           registre utilise

Publier un logiciel

Tout le monde peut contribuer : un dossier, un manifeste, une pull request.

  1. Forkez le dépôt et copiez packages/{{.Example}}/ vers packages/votre-nom/.
  2. Écrivez vos fichiers Lua : 64 Ko au plus chacun, Lua 5.4, et l'API de TERMINA (term, key, fs, net, win...).
  3. Vérifiez avec go run ./tools/mkindex, puis ouvrez une pull request. La CI refait les vérifications.
  4. Une fois fusionné, votre logiciel arrive ici et sur toutes les machines après un pkg update.
-- packages/snake2/package.lua
return {
  name = "snake2",
  version = "1.0.0",
  description = "Snake en couleurs",
  author = "Ada Lovelace",
  license = "MIT",
  bin = { "snake2" },      -- commandes A>
  depends = { "tui" },     -- autres logiciels
}
